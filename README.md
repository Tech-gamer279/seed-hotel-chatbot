# SEED Resort AI Concierge

  A full-stack hotel AI chatbot for SEED Resort — built with React, Vite, Express 5, PostgreSQL, Drizzle ORM, and OpenAI streaming.

  ## Stack
  - **Frontend**: React + Vite + Tailwind CSS + Framer Motion
  - **Backend**: Express 5 + PostgreSQL + Drizzle ORM
  - **AI**: OpenAI GPT streaming (SSE)
  - **Auth**: Replit OIDC

  ## Setup
  See `.env.example` for required environment variables.
